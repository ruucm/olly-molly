# Claude Code Capabilities

Claude Code는 CLI 기반의 AI 도우미로, 소프트웨어 개발을 넘어 다양한 분야의 업무를 수행할 수 있습니다.

---

## 1. Software Development (소프트웨어 개발)

### 1.1 Frontend Development
- React, Vue, Angular, Svelte 등 프레임워크 개발
- Next.js, Nuxt, SvelteKit 등 풀스택 프레임워크
- TypeScript/JavaScript 코드 작성
- CSS, Tailwind, Styled Components 스타일링
- 반응형 디자인 및 접근성 구현
- 성능 최적화 (번들 크기, 렌더링)

### 1.2 Backend Development
- Node.js, Python, Go, Rust 등 서버 개발
- REST API, GraphQL 설계 및 구현
- 데이터베이스 스키마 설계 (SQL, NoSQL)
- 인증/인가 시스템 구현
- 마이크로서비스 아키텍처

### 1.3 Mobile Development
- React Native, Flutter 크로스플랫폼 앱
- iOS (Swift), Android (Kotlin) 네이티브 앱
- 모바일 UI/UX 패턴 구현

### 1.4 DevOps & Infrastructure
- Docker, Kubernetes 컨테이너화
- CI/CD 파이프라인 (GitHub Actions, GitLab CI)
- Terraform, Pulumi IaC
- AWS, GCP, Azure 클라우드 설정
- 모니터링 및 로깅 설정

### 1.5 Quality Assurance
- 단위 테스트, 통합 테스트 작성
- E2E 테스트 (Playwright, Cypress)
- 테스트 커버리지 분석
- 버그 리포트 작성 및 재현

### 1.6 Security
- 보안 취약점 분석 및 수정
- OWASP Top 10 대응
- 침투 테스트 지원 (인가된 경우)
- 보안 코드 리뷰
